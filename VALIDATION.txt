Known behavior: global SoulSync library/UI remains shared; this publisher
corrects personal file availability and target playlists afterward. Matching is
strict; uncertain versions stay pending. A playlist publishes only when all
source members are ready. Downloads remain SoulSync's responsibility. No
garbage collection, file deletion, playlist deletion or source DB mutation.

The sidecar installs pinned requests and cryptography versions, with Python 3.12
on Debian Bookworm. Linux libc renameat2 is required for exclusive atomic copy
publication. It does not import SoulSync and uses a separate writable state
directory. The original SoulSync image remains unchanged.
